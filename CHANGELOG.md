## [1.0.0-alpha] - 2026-09-27

Initial alpha release.

### Added
- Full Windows process tree with parent-child relationships
- PID, CPU %, memory, and SYSTEM/SERVICE/USER tag per process
- Open file handles per process
- Live network connections per process
- Live CPU + memory graphs updating every 2 seconds
- Three themes: Dark, AMOLED Black, White Glass
- Alert highlighting for high-CPU and high-memory processes
- Kill Process button with confirmation
- Filter box for process name or PID
- Keyboard shortcuts: F11, /, T, Esc
- Window size persistence between launches
- Automated GitHub Actions release workflow
